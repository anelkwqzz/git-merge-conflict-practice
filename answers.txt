1. Что такое Merge Conflict?
Это конфликт при объединении изменений в Git

2. Почему возник конфликт?
Потому что две ветки изменили одну и ту же строку по-разному

3. Почему важно создать обе ветки заранее?
Чтобы обе ветки начинались с одной версии файла

4. Чем отличаются git fetch и git pull?
fetch получает изменения, а pull получает и объединяет их

5. Для чего нужен Pull Request?
Для предложения объединить одну ветку с другой

6. Почему объединили origin/main в feature-message?
Чтобы получить изменения из main и решить конфликт до слияния через Pull Request

7. Для чего нужен Resolve Conflicts в PyCharm?
Для разрешения конфликтов в файлах

8. Что такое Result?
Это итоговая версия файла после разрешения конфликта

9. Почему нужно сделать коммит?
Чтобы сохранить результат разрешения конфликта

10. Для чего нужна команда git push?
Чтобы отправить изменения на GitHub
